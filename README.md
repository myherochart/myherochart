
# My Hero Chart

Deploy in under 5 minutes:

## Option 1: Vercel
1. Go to https://vercel.com
2. Create a free account
3. Click "Add New Project"
4. Upload this folder or zip
5. Click Deploy

## Option 2: Netlify
1. Go to https://netlify.com
2. Drag and drop the folder or zip into the deploy area

## Local Run
```bash
npm install
npm run dev
```
